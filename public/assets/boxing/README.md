# Ringside character assets

`fighter-base.glb` is Quaternius's **Superhero Male** mesh and humanoid rig from
[Universal Base Characters](https://quaternius.com/packs/universalbasecharacters.html),
published under CC0 1.0. The original license is included alongside it.

The image-free GLB conversion comes from
https://github.com/programasweights/avatar/blob/main/public/assets/character.glb
(downloaded 2026-10-31). Mesh, normals, weights and bones are preserved.
The game adds its own materials, boxing equipment, hairstyles and procedural poses.
The eight PNG portraits are rendered from this same dressed model.

No runtime asset requests to external services are needed.
